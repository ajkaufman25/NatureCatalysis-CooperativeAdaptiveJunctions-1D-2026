# SI-facing numerical outputs

The CSVs in this directory were generated by the validated full numerical run recorded in `validation/si_alignment/`. Electronic energies and energy differences are in eV; catalyst electrode potentials and voltage differences are in V. All numerical values retain calculation precision. See `docs/NOTATION.md` and `docs/OUTPUT_SCHEMA.csv`.

`operating_states.csv` reports the finite-current AA/BA solutions. Four `*_dark_equilibrium_profile.csv` files and `dark_equilibrium_states.csv` use generation off, a common 0-V catalyst potential and Faradaic exchange disabled. Dark quantities do not inherit the old fixed-redox starting-state interpretation.

`AA_thickness_sweep.csv` contains 62 global/refined endpoints. `AA_thickness_plot_data.csv` contains the 31 global points used in current Figure S19. The refined points are preserved without being inserted into that publication curve.

`selected_catalyst_off_states.csv` is an exception to numerical recomputation: it transcribes the displayed selections in the SI, with explicit source/selection-status columns. The reference SI does not provide the additional constraint needed to reconstruct particular AA/AB/BA profiles uniquely. These entries are not used to determine finite-current operation. The separate BB diagnostic recomputes its conventional 0.150-V open circuit.

The native sweep's five zero-asymmetry rows are marked `symmetry_assignment_no_BVP`. All 25 nonzero-asymmetry rows were solved and checked. No analytical assignment, imported selection or historical diagnostic curve is represented as a newly solved finite-current state.
